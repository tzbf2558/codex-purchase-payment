所以「购买 Codex」这件事，实际拆开是两件事：买一个能覆盖 Codex 用量的 ChatGPT 套餐，以及解决付款这条路。

## 三条路，选哪条取决于你有没有海外卡

把 Codex 跑起来，认证方式只有两种：用 ChatGPT 账号登录，走订阅包含的额度；或者用 API Key 登录，走按 token 实时扣费。前者是订阅逻辑，后者是账单逻辑，混起来算最容易糊涂。

三件事值得先分清楚：

1. **订阅路径**——额度跟着套餐走，月底不会收到一张看不懂的账单。日常写代码、改 bug、跑重构，大部分个人开发者走这条。
2. **API Key 路径**——适合企业、需要接入自有账单体系或做自动化的场景。成本完全由 token 消耗决定，输入、输出、上下文全算钱。
3. **团队席位**——Business 和 Enterprise 工作区可以加「仅限 Codex」席位，采用即用即付、按 token 计费，不设速率限制。有个时间点需要注意：2026 年 6 月 24 日之后，Business 套餐不再提供新的 Codex 即用即付席位，已经存在的席位不受影响。

对中国大陆用户来说，真正的门槛不在选套餐，而在最后一步付款。截至 2026 年 8 月，OpenAI 的 ChatGPT 支持地区列表里没有中国大陆，有台湾。海外信用卡、账单地址、风控拒付，这三样轮流卡人。

## 额度才是真正决定花多少钱的东西

Codex 的限额不是按「发了几条消息」算的，是按每条消息烧掉多少 token 算的。同样的 Plus 套餐，有人一个月绰绰有余，有人两三天就撞到上限，区别几乎全在上下文长度上。

几个常见的隐藏消耗：

- 让它读一个 2000 行的文件再改，整个文件都变成输入 token 发出去
- 对话聊到第 50 条，前面 49 条作为上下文每次都重发
- 项目根目录放了一份啰嗦的 AGENTS.md，每条消息都被塞进去一遍

想随时知道还剩多少，可以在活动的 Codex CLI 会话里输入 `/status`。接近限额时，切到成本更低的模型能让额度撑得更久。另外本地消息和云端聊天共用同一份套餐额度，可能还叠加每周限额，这些都在官方文档里有说明。

至于 Plus、Pro 5x、Pro 20x 怎么选，有个很朴素的判断办法：先记一周。触发了几次额度提示、每次等多久、有多少任务因此换成低档模型、这些等待实际造成多少损失。如果一周下来几乎没被卡过，那 Pro 就是多花 100 美元买心理安慰。

## 几个高频问题

**Codex 能单独买吗？**
不能。它跟着 ChatGPT 订阅走，最低门槛是 Plus。Go 档名义上包含 Codex，但额度基本只够体验。

**代充和共享账号是一回事吗？**
不是。共享账号是很多人用一个号，聊天记录不私密、随时可能换号；代充是你自己的账号，平台替你完成订阅动作。两者风险不同，别混为一谈。

**用 API Key 是不是更省钱？**
取决于使用强度。低频、自动化的调用走 API 更可控；每天长时间交互式写代码，订阅制的额度通常更划算。

**邀请码能省多少？**
按平台现有规则是 1 美元。听起来不多，但它是下单就能减的那种，没有额外门槛。

**如果要买 Pro，选 5x 还是 20x？**
先问自己一个问题：过去一个月，你有没有因为额度用尽而被迫停下工作、或者换模型交付过？没有的话，Plus 就够了。有，而且这种情况每周都发生，再考虑往上加。
